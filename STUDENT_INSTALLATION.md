# EW AI Work Coach v0.1.0 學員安裝與使用說明 / Student Installation and Usage

## 繁體中文

### 手機安裝

1. 更新 ChatGPT App 並登入自己的帳戶。
2. 開啟「插件／Plugins」頁面。
3. 搜尋 **EW AI Work Coach**，或開啟公開頁連結。
4. 點選安裝。
5. 開啟新聊天，以 `@EW AI Work Coach` 啟用。

### 你可以怎麼開始

你不必先記住管理理論或工作法名稱。可以直接描述真實工作問題，EW AI Work Coach 會協助你選擇適合的方法、補足關鍵資訊與證據，並整理成可執行、可追蹤、可檢查的工作卡。

### 三個快速入口

- `Help me handle a workplace problem. / 幫我處理一個工作問題。`
- `Help me choose the right work method. / 幫我選擇適合的工作方法。`
- `Apply a method I specify. / 使用我指定的工作方法。`

### v0.1.0 支援的方法

- 5W1H：任務釐清
- SMART：目標具體化
- Time Quadrants：優先順序
- Fishbone + optional 4M1E：原因假設與證據缺口
- PDCA：改善循環
- 5S：現場整理、標準化與維持

同一案件切換工作法時，請留在原對話中，讓已知事實、負責人、期限、證據與待確認事項保持一致。未驗證的原因只能標示為假設；完成行動也不代表改善效果已經驗證。

## English

### Install on mobile

1. Update the ChatGPT app and sign in.
2. Open the Plugins page.
3. Search for **EW AI Work Coach**, or open its public listing.
4. Install the plugin.
5. Start a new chat and mention `@EW AI Work Coach`.

### Ways to start

You do not need to memorize management theory or method names. Describe the real workplace problem. EW AI Work Coach helps choose a suitable method, fill critical information and evidence gaps, and produce an actionable, trackable, checkable work card.

### Quick starters

- `Help me handle a workplace problem. / 幫我處理一個工作問題。`
- `Help me choose the right work method. / 幫我選擇適合的工作方法。`
- `Apply a method I specify. / 使用我指定的工作方法。`

### Methods supported in v0.1.0

- 5W1H: task clarification
- SMART: objective definition
- Time Quadrants: prioritization
- Fishbone + optional 4M1E: cause hypotheses and evidence gaps
- PDCA: improvement cycle
- 5S: workplace organization, standardization, and sustainment

When switching methods for the same case, stay in the original conversation so facts, owners, dates, evidence, and unresolved items remain consistent. Unverified causes remain hypotheses, and completing an action does not prove that the improvement was effective.
